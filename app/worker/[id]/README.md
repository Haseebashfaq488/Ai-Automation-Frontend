# `app/worker/[id]/` — Autonomous Worker Cockpit

## 1. Directory Role & Boundary
The `app/worker/[id]/` directory implements the **Worker Cockpit** (`/worker/{sessionId}`). It provides deep real-time observability, human-in-the-loop plan review, live streaming output, automated test verification, and architectural session handovers for a single autonomous worker session.

| Tab Key | Title | Deliverable / Responsibility | Backend Endpoint |

## 4. Key Sub-Components inside `page.js`

### A. `LiveWorkerTerminal`
* Renders the continuous stream of CLI output.
* Handles auto-scroll toggle and copy-to-clipboard functionality.

### B. `PlanApprovalCard`
* Shown during `awaiting_plan_approval` status (Job 1 completion).
* Provides "Approve Plan (Start Execution)" and "Request Plan Revision" with custom guidance input.

### C. `HandoverAndGraphPanel`
* **Knowledge Graph Card**: Displays status of `graphify` AST index, scope path, and copyable query helpers (`graphify query`, `graphify path`, `graphify explain`).
* **Living Documentation (Manifests)**: Chips of all touched subfolders maintaining localized `README.md` files.
* **Session Handover Brief**: Rendered markdown and structured decision notes for subsequent workers.

### D. Right Sidebar (Control Rail)
* Overall progress percentage & current step indicator.
* Checklist of completed items and encountered errors.
* Live Event Bus stream.
* Intervention input: Allows the operator to inject steering instructions into a running session (`POST /workers/{id}/intervene`).

## 5. Critical Invariants & Gotchas
* **Dual EventSource Lifecycle**:
  * `/workers/{id}/stream` delivers raw CLI text deltas.
  * `/workers/{id}/events` delivers high-level structured lifecycle JSON events.
  * Both must close when receiving `WORK_COMPLETED` or `result`, or when the component unmounts.
* **Non-Blocking Fetch**: Auxiliary deliverables (`artifacts`, `plan`, `test-results`, `handover`, `resolution`) are fetched gracefully. If an endpoint returns 404 (e.g. before tests or handover have finished), the UI continues rendering without crashing.
* **Desktop CLI Synchronization**: The `Launch CLI` button calls `/workers/open-agy-terminal` or `/workers/open-terminal` using `state.fs_scope` to ensure external terminal sessions spawn in the correct workspace path.
